# 染域 CHROMA

**chroma-table** 是一款 2–8 人的局域网染色策略桌游：从出生点扩张领地，用墨水争夺染井，用战术牌与海克斯强化改变打法。

原生 Node.js + HTML/CSS/JavaScript，无第三方运行依赖，无需数据库，无需构建前端。主机运行服务，朋友通过电脑或手机浏览器加入。

## 下载与启动

1. 安装 [Node.js](https://nodejs.org/zh-cn/download)，要求 **22.8 或更高版本**；开发与测试使用 Node.js 24。
2. 在 GitHub 仓库点击 **Code → Download ZIP**，下载并解压。
3. Windows 双击 **启动染域.bat**。macOS / Linux 可运行 `sh start.sh`。也可直接运行：

```sh
node server.js
```

不需要 `npm install`。不要直接双击 HTML 文件，游戏需要通过服务器访问。

主机打开 **http://localhost:3000**。朋友连接同一 Wi-Fi，打开终端中显示的局域网地址，在首页房间列表选择加入，也可以使用带房间号的分享链接。

打不开时，检查主机防火墙是否允许 Node.js 在专用网络通信，以及 Wi-Fi 是否开启了访客隔离。主机需保持开机和联网。

## 能玩什么

- **2–8 人联机**：随机地图、随机首位、共享天气与战术抽牌。
- **GM 控制台**：玩家昵称精确为 ww / ww. 时，入房后按 Ctrl+F1 管理积分、战术牌和强化；请求由服务端逐次判权。
- **个人锚点**：8 款四阶外观，默认不佩戴，用游戏积分解锁，高阶款拥有轨道、光效、粒子和落色特效。
- **积分与收藏存档**：完整对局奖励为最终得分 + 20，获胜额外 +30；重启保留，重复结算不重复发分。
- **36 色玩家色盘**：大厅自选颜色、占用互斥、一键恢复默认，开局后锁定；重连和再来一局保留颜色。
- **房间列表**：显示房主、人数和轮次，可加入或实时观战。
- **11 步新手教程**：单人学习染色、抢色、加固、三种技能、海克斯和结算。
- **固定测试房间 000001**：自带一名机器人，一个人也能开局。
- **36 张永久强化**：白银、黄金、棱彩各 12 张，全场每次刷新同一品阶。
- **公开对局信息**：可查看玩家手牌、技能刷新、候选强化、重抽与最终选择。
- **重连与托管**：误退出后，可在同一浏览器返回原席位；房主退出自动转交。
- **同步兼容**：优先 SSE，受阻时自动改用 HTTP 轮询，并尝试恢复推送。

## 怎么获胜

每位玩家完成一次回合算一轮，房主可选 6 / 10 / 15 轮。最后一轮结束后，**总积分最高者获胜，同分并列**。

普通地块与出生点每格 1 分，染井每座 4 分。总积分由当前领地分与强化获得的永久积分组成；部分强化会改变地块分值。地块被抢后，占领分随归属转移。

每回合通常获得 3 点墨水：染空地 1 墨，普通抢色 2 墨，加固 1 墨。泼墨 3 墨、破色 1 墨、飞染 2 墨。用完墨水后记得点击「结束回合」。

完整说明见 [游戏规则](docs/RULES.md)。

## 运行范围与限制

- 房间和对局保存在内存中，**重启服务会清空**。
- 玩家身份保存在浏览器，同一主机地址、同一浏览器才可恢复；清除站点数据会失去身份。
- 房间中的手牌、强化候选和选牌记录向玩家与观众公开。
- 当前默认面向同一局域网，**没有配置外网入口**。已适配 HTTPS 来源校验、外网分享地址和 SSE 轮询降级；具体穿透服务需自行配置。
- 这是可玩原型，尚未针对不可信公网环境完成部署加固，也没有账号系统、对局永久存档或互联网匹配；锚点积分和收藏会保存在主机 data/profiles.json 中。

## GM 权限

仅玩家昵称 ww 或 ww. 可在房间中按 Ctrl+F1 打开控制台，支持向本房间目标玩家发积分、战术牌和强化卡。控制台内容由受保护接口提供，普通玩家、观众、机器人不下发界面，直接请求返回 403。无额外管理员或隐藏后门。

注意：目前没有账号系统，昵称可自行填写；任何人以 ww / ww. 入房也会被视为 GM。若需防止昵称冒用，应另行绑定身份或增加认证。

积分操作有持久化去重记录；卡牌遵守手牌上限、重复及互斥规则。完整规则见项目结构说明。

## 积分、锚点与存档

大厅可预览、解锁、佩戴或卸下锚点，外观不影响胜负。游戏积分单独累计，不消耗对局得分；教程、观战和未完赛房间不发积分。

收藏沿用当前浏览器身份，清除站点数据、换浏览器或换域名不会自动继承。data/profiles.json 为私人进度文件，不包含在源码包中。更换主机时需另外迁移 data 文件夹，也可通过 CHROMA_DATA_DIR 指定数据目录。详见 [存档迁移](docs/HOSTING.md)。

## 更换主机与后续穿透

复制完整源码包即可在另一台电脑启动。可选 server.config.json 支持 host、port 和 publicUrl；环境变量 HOST、PORT、PUBLIC_URL 优先。Windows 与 macOS / Linux 启动脚本支持 runtime 目录中的便携 Node。

详见 [服务器启动与配置](docs/HOSTING.md)。配置 publicUrl 不会建立外网入口。

## 修改端口

PowerShell：

```powershell
$env:PORT=3001
node server.js
```

macOS / Linux：

```sh
PORT=3001 node server.js
```
